# Introify wordmark

Six colour variations of the user-supplied `introAsset 1.svg`. All original path, rectangle and circle geometry is preserved. Lettering is outlined and requires no font. Exports use transparent backgrounds.

- Signature: white and original lime; for dark green surfaces.
- Forest: deep green and olive; for light site surfaces.
- Periwinkle: ink and violet; for the temporary landing study.
- Nightfall: white and lavender; for dark violet surfaces.
- Ink: single-colour dark.
- White: single-colour reverse.

The shared React wordmark uses the same drawing with theme-aware colours. The original supplied SVG remains unchanged.
